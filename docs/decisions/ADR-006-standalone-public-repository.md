# ADR-006：迁移为独立公开仓库

- 状态：Implemented
- 日期：2026-08-06

## 背景

RelayHub 最初在 Clowder AI 工作区的子目录中实现，以便持续参考产品问题和架构边界。但长期保留在父仓库会混入无关历史、继承父项目规则，并且只能推送到 Fork 的特殊分支，不利于简历展示和独立维护。

## 决策

1. 将 `relay-hub/` 的专属提交历史通过 subtree 提取，目录内容重写为独立仓库根目录。
2. 独立本地仓库使用 `/Users/xuzishuo/Documents/relay-hub`，默认分支使用 `main`。
3. 独立 GitHub 仓库使用公开的 `zishuo-xu/relay-hub`。
4. 后续所有实现、文档、验证、提交和推送都在独立仓库完成。
5. 原嵌套目录暂时保留为迁移备份，不自动删除，也不继续作为开发主目录。

## 结果

- 面试官可以直接查看只属于 RelayHub 的代码和提交历史。
- 项目不再受 Clowder AI 的分支权限、根目录配置和工作约定影响。
- 每次修改可以直接提交并推送 `origin/main`，不再经过父仓库 Fork 分支。
- 迁移保留历史证据，同时避免复制一份没有开发过程的全新快照。
