# RelayHub Work Items

本目录是委派开发任务的 canonical register。工作规则见 [`../10-delegated-development-workflow.md`](../10-delegated-development-workflow.md)。

## Active

| ID | 标题 | Owner | 状态 | 依赖 | Work Item |
|---|---|---|---|---|---|
| - | 当前没有已分配任务 | - | - | - | - |

## Recently completed

| ID | 标题 | 最终 main commit | Work Item |
|---|---|---|---|
| - | 尚未使用本协议完成任务 | - | - |

## 维护规则

- Architect 创建 Work Item 后，必须在此登记。
- 状态变化时同时更新登记表和 Work Item 文件。
- 登记表只保存索引；完整范围、证据、Findings 和验收结论保存在对应 Work Item。
- `DONE` 后从 Active 移入 Recently completed，保留审计记录。
- 不删除已完成或取消的 Work Item。
